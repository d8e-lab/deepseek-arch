# DeepSeek Arch v1.4.1

> 渲染与交互体验大更新：界面渲染层全面重构，对话更实时、更清晰。

## 🖥️ 界面与交互体验

- **Render SDK 架构升级** — 界面渲染能力重构为标准化 SDK（`deepseek-arch/render`），更稳定，为后续扩展与第三方集成铺路
- **子代理详情统一** — 查看子代理运行详情时，显示格式与主会话完全一致，更清晰易读
- **Ctrl+O 全屏视图增强** — 可完整查看模型的思考内容，不再截断
- **命令补全可滚动** — 补全建议较多时支持滚动浏览全部选项，不再止步于前几条
- **正文实时显示** — 模型调用工具前先实时输出文字，对话节奏更自然，不再等整个工具循环结束

## ✨ 新能力

- **浏览器启动错误智能提示** — 启动失败时自动分类并给出修复指引（缺失浏览器二进制 / 系统库缺失 / 沙箱限制）
- **本地测试模式** — `--mock` 参数使用内置模拟提供商，无需 API key 即可体验
- **自主验证工具** — `--self-interaction` 参数暴露子会话测试工具，支持模型自主验证前端展示

## 🔧 Bug 修复

- 修复补全列表选项过多时无法选到后面条目的问题
- 修复工具调用过程中模型正文延迟显示、内容堆积的问题
- 修复技能激活提示可能打断模型工具调用序列的问题

## 📦 安装

```bash
# Arch Linux (AUR)
yay -S deepseek-arch

# npm
npm install -g deepseek-arch
```
