# DeepSeek Arch v1.5.2

> 对话更聪明、界面更顺手：新会话自动生成标题、三档展示模式随心切换、默认 YOLO 自动放行——以及 Subagents 总览视图的全面体验升级。

## 🖥️ UI/UX 优化

### Subagents 总览视图（Ctrl+T）升级
- **轨迹滚动浏览**：↑↓ / PgUp / PgDn 可以滚动查看选中 subagent 的完整执行轨迹（不只是贴底跟随最新输出）
- **耗时显示更准确**：已结束的 subagent 耗时固定不再跳动，视图刷新定时器随之停表
- **历史记录渲染修复**：旧版词碎片记录不再逐词竖排，正文恢复为正常的段落/表格展示
- **边界清理**：视图返回与命令收尾不再产生重复分隔线，Subagents 列表稳定沉底

### 会话标题自动生成
- 新会话的第一条用户消息自动成为会话标题（≤20 字），`resume` 列表按标题一眼识别会话内容，告别一列 UUID

## 🎛️ 新功能

### 展示模式三档切换
- `--short` 极简：think 最多 4 行，工具只显示「调用 + 成功/失败」（文件修改的 diff 除外）
- `--normal` 平衡（**新默认**）：think ≤4 行、工具结果 ≤6 行
- `--detail` 完整：think 5 行后折叠、实时工具输出、结果 ≤12 行
- 三档互斥，未指定时默认 `normal`

### 展示参数可配置
- 新增 `[display]` 配置段：内置三档预设的每项数值（think 实时行数 / 工具结果行数 / 是否显示实时工具输出 / 是否隐藏非文件工具结果）均可按档位覆盖，满足个人偏好

### 默认 YOLO 开启
- 新装用户默认自动批准工具执行（`--no-yolo` 可临时关闭，`/yolo` 可写回配置），开箱即用的 agent 体验

## 🔧 Bug 修复

- 修复视图关闭 / 命令收尾后输出区出现重复分隔线的问题
- 修复 Subagents 总览视图中旧会话记录正文被逐词竖排显示的问题
- 修复 subagent 结束后耗时仍在跳动、视图刷新不停止的问题

## 🧱 内部架构演进（为后续组件化铺路）

- 表示层正交模块化重构：输出统一收敛到 ScreenBuffer、底部区域容器化（BottomArea）、两个全屏视图公共生命周期收敛至 OverlayPane 基类
- 新增回归测试固化 8 个历史光标定位类修复，界面稳定性更有保障

> 本次全部变更均已在 main 分支，无破坏性变更，升级即用。

## 📦 安装

```bash
# Arch Linux (AUR)
yay -S deepseek-arch

# npm
npm install -g deepseek-arch
```

> 已安装旧版本的用户：`npm install -g deepseek-arch@latest` 升级即可。
