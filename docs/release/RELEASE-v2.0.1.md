# DeepSeek Arch v2.0.1

> 记忆更准、更快、更省上下文：升级即时生效、进出清单主动告知模型，读取不再扫描整个记忆库。

## 🧠 记忆更准

- **升级/淘汰即时生效**：刚被用到并达到阈值的记忆立刻升级；已进入"待销毁"的记忆一旦再次被用到，
  马上回到"待观察"，不用等到下次结算。
- **进出可见清单会告知模型**：新增/升级会连同一行简介告诉模型；退出清单、被取代或被删除也会给提示——
  模型不会再拿着过期清单当现状。
- **归纳进度按会话记录**：新开一个会话不再抹掉旧会话的进度，也不会把同一段对话反复归纳。

## ⚡ 记忆更快、更省

- 每层新增一份"总表"作为内存工作集：日常读取直接在内存里完成，
  **不再每轮把整个记忆库重新读一遍**（此前每轮要读几百个条目文件）。
- 单条记忆超过 64KB 时截断返回，并在界面提示——提醒你把长内容放进普通文件而不是记忆里。

## 🔒 安全与可靠性

- `memory_read` 现在**只能读取记忆目录内**的文件（此前可以读到任意路径）。
- 多个进程（TUI 与 `chat --prompt`）同时写记忆时会加锁串行，避免互相覆盖。

## 🔧 Bug 修复

- 修复了召回挑选失败时**整份记忆清单消失**的问题（现在会退化为按更新时间给出，绝不因此少给）。
- 修复了候选区里出现**已删除条目**、并被后台代理反复"提升"却始终无效的问题。
- 修复了"把偏好明确降到候选"时**同一次写入又把它抬回可见**的抖动。
- 修复了变更提醒一次超过 6 条时，多出来的变更**永远不会再被提示**的问题。
- 修复了上下文压缩后，之前注入过的记忆可能**永久消失**的问题。
- 修复了归纳在超时/超限被中止后**每轮重试同一段**、反复消耗的问题。

## ⚠️ 变更

- **`chat --prompt` 现在必须搭配 `--workspace`**：非交互调用（cron / 心跳 / 脚本）的当前目录不可控，
  缺省会让项目层记忆与 runtime 文件落到错误的位置。缺失时直接报错退出。
- **移除"到期提醒"（`remindAt`）**：记忆不再携带定时提醒；此前说"以后再提醒我"的事项按普通记忆记录。

## 📦 安装

```bash
# 任意发行版（GitHub Release 预编译包，免构建）
npm install -g https://github.com/d8e-lab/deepseek-arch/releases/download/v2.0.1/deepseek-arch-2.0.1.tgz

# Arch Linux：AUR 尚未同步到 2.0.x（仍为 1.5.3），如需最新版请用上面的 GitHub Release 包或源码构建
git clone https://github.com/d8e-lab/deepseek-arch.git
cd deepseek-arch/aur && makepkg -si
```

> 本项目**未发布到 npm registry**，请勿使用 `npm install -g deepseek-arch`。
